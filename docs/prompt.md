# 試したプロンプト

今日以下のような1dayハッカソンが開催されます。
https://luma.com/3ffo8nmc?tk=0j5WCJ

ハッカソンで入賞するために恐ろしく質の良いWeb3ミニゲームを開発したいです。
ハッカソンで入賞できるアイディアを考えてそのアイディアを実現させてください。

例えば以下のようなゲームだと面白いですね！

- ポーカーゲーム
  - 勝ったらトークンをもらえる
  - 負けたらトークンを没収される

対象のブロックチェーンは Base Sepoliaです。
https://docs.base.org/get-started/base

Mini Appという機能を使ったプロダクトを作成する必要があります。
https://www.base.org/build/mini-apps

template用のベースプロジェクトを`template`フォルダ配下に用意しました。
基本的な機能、ソースコードは全てこのフォルダに揃っています。
この中身をベースにフロントエンドのデザインを改修してください。 

開発要件も別途まとめているのであなたに与えられた背景情報を正確に把握し、最高のアプリを開発してください。

よろしくお願いします。
